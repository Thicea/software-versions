# software-versions

Windows Server 2022 関連ソフトウェア33項目の調査結果を掲載する静的サイトです。ビルドや外部ライブラリ、APIキーは不要です。調査済みの値と、公式情報を取得できなかった項目を区別して掲載します。現在の調査範囲と制約は `research/2026-11-09-network-restored.md` を参照してください。

## ローカル表示

リポジトリのディレクトリで実行します。

```sh
python3 scripts/render.py
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザーからローカルのポート8000を開きます。`index.html` は調査結果を含む単独のHTMLです。JavaScriptを使わず表示できます。

## 単発の調査結果を更新する

1. 指定の調査プロンプトで、その実行時点の全33項目をオンライン調査します。出力は指定どおりのMarkdown表にします。
2. 公式原文と照合した結果を `versions.json` に転記します。`products.json` は製品名・順序の照合用です。指定系列、CPUアーキテクチャ、CU/GDRを区別してください。
3. `checkedAt` に実際の調査日時をタイムゾーン付きで設定します（形式例：`2026-11-09T18:30:00+09:00`）。ファイル編集日時や公開日時で代用しないでください。
4. `python3 scripts/render.py` を実行します。33項目の形式検証後、`templates/index.html` と調査データから `index.html` を生成します。ページ表示も確認します。
5. 変更をコミットし、`main` にプッシュします。Pages設定後は、公開元ブランチへの更新で掲載内容が反映されます。
6. GitHub Pagesのデプロイ成功と、公開ページの調査基準日時・更新内容を確認します。ユーザーから公開保留の指示がない限り、ここまでをサイト更新作業の完了範囲とします。

各項目の形式：

```json
{
  "no": 1,
  "name": "Microsoft Visual C++ 2013 Redistributable (x86)",
  "version": "今回未確認",
  "releaseDate": "未確認",
  "sources": [
    {"label": "公式参照先（未確認）", "url": "https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist"}
  ]
}
```

- `version`：確認したバージョン・KB・ビルド。確定できない場合は「最新版未確定」、今回確認できない場合は「今回未確認」。必要な短い注記もここに記載します。
- `releaseDate`：正式公開日を `YYYY/MM/DD` で指定。不明は「未確認」。ページ更新日と混同しないでください。
- `sources`：公式URLを配列で指定。不一致があれば両方を掲載し、リンク名で言語や掲載値を区別します。取得できた公式情報と取得不可の参照先を、リンク名で区別してください。
- No.15・16はAgent単体の公開値や製造元・系列を確認できていません。候補資料は同一製品と確認済みの情報として扱わないでください。
- 過去参考の記述・バージョンは掲載しません。生成コマンドは該当記述があるデータを拒否します。
- 調査基準日時は保存した固定の日時を日本時間で表示します。閲覧日時・生成日時へ自動的に置き換えません。
- 検証コマンドはデータ形式を検査します。最新版・公開日・公式サイトかどうかの正しさは判定しません。

## GitHub Pagesで公開する

リポジトリ管理者が GitHub の **Settings → Pages → Build and deployment** で以下を選択します。

- Source: **Deploy from a branch**
- Branch: **main**、フォルダー: **/ (root)**

保存後、GitHub側のデプロイ完了を確認し、Pages設定画面に表示されるURLを開いてください。「今回未確認」「最新版未確定」の項目は、最新版を確認済みという意味ではありません。公開元へのプッシュ後、GitHubのActionsでPagesのデプロイ結果を確認してください。

定期タスク・自動調査・パッチ適用処理は含みません。データ更新とGitHub Pagesへの公開は別の操作です。
